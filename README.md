# 대체근로자 임금 계산기 1.6.3

`대체근로자 임금 계산기_1.6.3.exe`를 실행하세요. 별도 설치나 DLL 복사는 필요하지 않습니다.

## 이번 수정

- 설정의 테마 선택을 제거하고 파스텔 민트를 기본 색상으로 고정했습니다. 이전 설정이나 계산자료에 다른 테마가 저장되어 있어도 민트로 표시합니다. 기존 파스텔 카드와 초록색 엑셀·빨간색 PDF 버튼은 유지합니다.
- 기관·신청서 정보와 저장 경로를 위쪽 두 영역에 배치하고, 프로그램·공휴일 업데이트는 아래쪽 넓은 영역으로 배치했습니다. 저장 경로 입력란·폴더 선택 버튼의 높이와 간격, 버전·자동 확인·상태 안내의 위치를 정리했습니다.
- 생년월일 / 주민번호 입력란을 **생년월일**로 변경했습니다. 생년월일은 6자리 또는 8자리로 입력할 수 있습니다. 주민번호를 붙여넣거나 예전 계산자료를 불러오면 앞의 생년월일 6자리만 남깁니다. 주민번호 뒷자리는 현재 계산자료에 유지하지 않습니다. 기존 원본 파일은 변경하지 않습니다.

## 사용

대상자·계약 → 근무일·주휴 → 임금·공제 → 명세서·신청서 순으로 입력합니다. 자료 불러오기에서 기존 계산자료나 프로그램이 만든 임금산정표를 이어서 편집할 수 있습니다. 자료 저장과 문서별 엑셀·PDF 저장은 별개입니다. 종료 시 계산 입력은 초기화되므로 필요한 자료를 먼저 저장하세요. 기관 정보와 저장 경로·업데이트 설정은 유지됩니다.

직종명은 직접 입력해 부분 검색하고 목록에서 마우스 또는 방향키·Enter로 선택할 수 있습니다. Esc는 취소입니다. 선택을 확정하기 전에는 직종이나 단가가 바뀌지 않습니다.

달력은 계약기간을 하나로 표시하며, 세 탭 오른쪽의 계약·주휴 기준 버튼으로 기준을 설정합니다. 주휴 표는 항상 4주 공간을 확보하고 5주차는 스크롤합니다. 2026.10.30~11.06 평일 하루 8시간 사례는 계약기간 48시간÷6일=8시간으로 표시합니다. 계약기간 비율과 실제 계산 기준이 다르면 실제 주 기준 산식을 함께 표시합니다. 계산 엔진은 그대로 유지했습니다.

명세서·신청서의 미리보기는 실제 출력 양식을 축소한 **가상 자료 예시**이며, 클릭하면 확대됩니다. 현재 입력값이 반영되는 실시간 미리보기는 아닙니다. 저장 파일에는 현재 대상자의 입력값이 적용됩니다.

## 검증 및 환경

총 **1,194개 검사**를 통과했습니다. 최소·기본 창 크기에서 설정 카드와 글자·입력란·버튼의 겹침, 민트 고정, 생년월일 입력·기존 자료 변환 및 기존 계산·엑셀 출력·저장 복원을 확인했습니다. 상세 기록은 검증결과.txt와 검증기록 폴더에 있습니다.

Windows / .NET Framework용 단독 실행파일입니다. PDF 저장에는 Microsoft Excel이 필요합니다. 기존 단가·보수 기준 및 출력 서식은 유지했습니다.

소스 ZIP을 풀고 `src/build.ps1`을 실행하면 `src/build/ShortTermPayroll.exe`가 만들어집니다. 전체 검사는 `verify-pastel.ps1`로 실행합니다. 이번 버전은 로컬 수정 빌드입니다.

# 대체근로자 임금계산기 · 정식1.4.0

2026-10-15. 표시 버전은 **1.4.0**, 자동 업데이트 구분용 파일 버전은 **1.4.0.6**이다. 기존1.4.0 배포와 테스트판에서도 새 수정본을 인식한다.

## 이번 변경

- 날짜별 계약의 주휴 1회 지급시간을 매주 누적해서 바꾸던 방식을 수정했다. **4주 이하 계약은 계약기간 전체의 약정 소정근로시간 ÷ 같은 기간 통상근로자의 소정근로일수**로 계산한다. 마지막 부분 주의 약정도 그 기준시간 계산에 포함된다.
- ‘계약·주휴 기준’ 창에서 **확인 근거/메모**와 맨 아래 **확인했습니다 체크박스**를 제거했다. 메모·확인 서명을 출력 조건으로 사용하지 않고, 유효한 입력은 즉시 계산한다. 이전 파일의 해당 메모·확인 서명도 새로 저장하지 않는다.
- 주휴 발생 여부와 지급시간은 구분한다. 개근·7일 근로관계 유지 등은 각 주 단위로 판단하고, 날짜별 4주 이하 계약의 주 평균 15시간 여부는 전체 약정기간 평균으로 판단한다. 결근은 약정 소정근로시간을 줄이지 않고 해당 주의 개근 요건에 반영한다.

## 교육자료 예시 확인

교육자료가 명시한 ‘월~금 5일 + 다음주 월~수 3일’ 구조에서, 계약상 5일을 하루 8시간씩 일하기로 약정했다면 40시간 ÷ 8일 = **5시간**이다. 주휴 1회가 발생하면 첫 주에도 5시간을 적용한다. 첫 주 3일만 다시 나눠 24시간 ÷ 5일 = 4.8시간을 지급하지 않는다.

동봉한 `예시_교육자료_주휴5시간.xlsx`는 공휴일 없는 2026-11-02~11-11 계약에 11/2·3·4·9·10을 각각 8시간 약정·출근한 가상 사례다. 원본 슬라이드의 ‘5월4일(월)~17일(다음주 수요일)’은 날짜·요일이 맞지 않으므로, 달력 날짜를 임의로 8일이라고 처리하지 않고 명시된 5+3일 구조를 옮겨 검증했다. 마지막 3일은 기준시간 계산에 포함되지만 추가 주휴는 발생하지 않는다.

## 입력 방법

1. 계약기간·직종·일 소정근로시간을 입력한다.
2. **근무일·주휴 → 계약·주휴 기준**에서 계약 형태, 근무요일, 통상근로자의 기준과 주휴 요일을 설정하고 **적용**한다. 확인 체크나 근거 메모는 없다.
3. 한 달력의 편집 대상을 바꿔 **계약근무일 / 근무상황부 / 통상근로자 근무일**을 입력한다. 출근 상태를 바꿔도 계약일이 바뀌지 않는다. 새 계약일을 추가해도 출근이 자동 입력되지는 않는다.
4. **근무일 자동 편성**은 약정일을 개근한 상태로 입력하는 기능이다. 실제 결근은 이후 달력에서 수정한다.
5. 임금·공제 등 입력과 계산 근거를 확인하고 엑셀을 저장한다. 출근 미확인, 약정 외 출근, 주휴일과 계약일 중복, 비교일 없음 등 실제 입력 모순은 계속 표시한다.

## 계약 형태와 산정 범위

**매주 같은 요일로 근무**는 주 단위 약정이 반복되는 계약을 입력하는 방식이다. 약정 주시간 ÷ 통상 주 근무일수로 계산하는 기존 고정 비례 방식을 유지한다. 월·수·금 각8시간, 주24시간 약정이고 통상 주5일이면 1회4.8시간이다. 달력에서 특정일을 비근무로 바꾸는 것으로 계약 자체를 변경하지 않는다. 기간 전체에 총 몇 일만 약정한 계약은 **날짜별로 다른 일정**을 사용한다.

**날짜별로 다른 일정**은 특정 날짜들의 약정 총량과 같은 기간 비교일수를 사용한다. 4주 이하에서는 모든 주휴 1회분에 같은 기준시간을 적용한다. 기존 9/15~10/8 날짜별 가상 예시는 96시간 ÷15일 =6.4시간으로, 개근한3주 합계19.2시간이다. 이전 테스트의4.8+6+6=16.8시간은 사용하지 않는다. 이19.2시간은 고정 주24시간 계약의14.4시간과 계약 전제가 다르다.

날짜별 모드는 법정 공휴일을 소정근로시간의 비례 산식과 통상 비교일에서 제외하는 기존 전제를 유지한다. 공휴일은 결근으로 처리하지 않으며, 해당 약정일의 유급 공휴일 임금은 별도 항목으로 계산한다. 공휴일을 통상 비교일에서 임의로 뺀 일수로 추정하지 말고 실제 계약·기관 기준에 맞춰 비교일을 입력한다. 첨부 교육자료 하나만으로 다른 계약의 공휴일 처리까지 확정한 것은 아니다.

1개월 미만이지만4주를 넘는29·30일 계약은 최대4주 산정기간을 넘겨 합산하지 않는다. 최초28일은 그 전체 구간을 사용하고, 잔여 날짜의 기준은 계약 종료일까지의 마지막28일을 사용한다. 잔여1~2일 때문에 다섯 번째 주휴가 발생하지 않는다.

발생 횟수는 프로그램이 지원하는 입사일부터 연속7일 구간으로 계산하며, 실제 주휴일은 지정한 요일에 표시한다. 별도 주간 기산점, 날짜마다 다른 일일 근로시간, 연장·휴일근로의 별도 약정 등은 자동 산정 범위에 포함하지 않는다. 당직전담실무원의 별도 계산 방식은 유지했다.

## 저장·불러오기·종료

기존 `.stpay`와 프로그램에서 저장한 임금산정표 `.xlsx`를 열어 이어서 수정할 수 있다. 이전 정식1.4 자료는 출근·결근·유급휴일 목록에서 약정일을 초기 복원하므로 계약 근무일·통상 비교일이 실제 계약과 맞는지 확인한다. 이전1.4.0.1의 별도 계약일·출근·비교일은 각각 보존한다. 금액은 새 산식으로 다시 계산한다.

새 저장자료는 버전7이며 구 정식1.4 및1.4.0.1에서 다시 열 수 없다. 기존 원본은 별도 보관한다. 불러오기만으로 원본 파일을 덮어쓰지 않는다. 임금산정표에는 주민번호 전체를 숨겨 넣지 않고 생년월일만 보존한다.

종료 시 저장 질문 없이 닫히고 재실행하면 이름·직종·근무일 등 계산 입력을 초기화한다. 기관·담당자 설정은 유지한다. 이어서 사용할 내용은 종료 전에 직접 저장한다. 신청서의 직종명→원근로자→성명 순서와 같은 연도 종료일의 연도 생략, 색상 영역과 정사각형 달력도 유지했다.
