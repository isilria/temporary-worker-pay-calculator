# 1개월 미만 대체근로자 임금계산기 · 정식 1.1

2026-09-16 배포. 정식 1.0의 계산 기능을 유지하고 전체 초기화 버튼을 추가했습니다.

## 다운로드

[최신 배포](https://github.com/isilria/temporary-worker-pay-calculator/releases/latest)에서 `ShortTermPayroll-1.1-windows.zip`을 내려받아 압축을 풀고 `대체근로자_임금계산기_1.1.exe`를 실행하세요. Drive에서는 `1.1_실행파일.zip`입니다. 단일 파일 `ShortTermPayroll-1.1.exe`도 같은 프로그램입니다.

## 새 기능: 초기화

제목 줄 오른쪽의 **초기화** 버튼을 누르면 확인 후 현재 작업을 초기화합니다. 근무 달력 버튼과 같은 150×38 크기, 테마색 배경, 흰색 글씨입니다.

- 대상자·계좌·대체 사유, 달력의 근무·결근 표시, 추가 지급·공제·고용보험 제외 사유, 지급일·신청 차수, 기관·신청서 입력을 초기화합니다.
- 계약일은 오늘부터 7일, 직종과 기준 단가는 기본값으로 돌아갑니다. 근무 달력은 비워지므로 새 계약에 맞춰 입력하거나 **근무일 자동 편성**을 누르세요.
- 기관 입력은 초기화된 상태로 자동 저장하여 다시 실행해도 이전 기관 정보가 나타나지 않습니다.
- 테마, 출력 폴더, 자동 업데이트·출력 파일 열기 설정은 유지합니다.
- 이미 저장한 .stpay 파일이나 생성한 엑셀·PDF 파일은 삭제하지 않습니다. 초기화 후 저장은 새 자료로 처리합니다.
- 확인창에서 **아니요**를 누르면 현재 작업을 그대로 유지합니다.

## 업데이트

정식 1.0에서 시작 시 확인 또는 설정 → **지금 확인**을 누르면 1.1을 안내합니다. 다운로드에 동의하면 실행 파일의 SHA256을 검증한 뒤 폴더를 엽니다. 현재 작업을 저장·종료하고 새 파일을 바탕화면에 옮겨 실행하세요. 자동으로 실행 중인 파일을 덮어쓰지 않습니다. GitHub 게시 직후에는 버전 안내 반영에 수 분 걸릴 수 있습니다.

## 검증 및 소스

Windows용 .NET Framework / AnyCPU. 계산·보고서, 화면, 당직·수당, 저장자료, 엑셀 출력, 업데이트와 초기화 회귀 검사를 수행합니다. 상세 결과와 실행 파일 SHA256은 배포본의 검증결과.txt를 참고하세요. 실제 프린터 인쇄는 검사하지 않았습니다.

`src/build.ps1`로 빌드하고 `package.ps1`로 검사 및 배포 ZIP을 생성합니다. 산출물은 `artifacts/v1.1.0`에 생성됩니다. 다음 배포 절차는 RELEASE.md를 참고하세요.
