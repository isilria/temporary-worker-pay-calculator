# 1개월 미만 대체근로자 임금계산기 · 정식 1.0

2026-09-16 정식 배포. 기존 2026-09-14 작업본 1.1의 기능을 유지하고 정식 버전 번호를 1.0.0.0으로 정리했습니다.

## 다운로드 및 실행

[최신 정식 배포](https://github.com/isilria/temporary-worker-pay-calculator/releases/latest)에서 `1.0_실행파일.zip`을 받아 압축을 풀고 `대체근로자_임금계산기_1.0.exe`를 실행하세요. 단일 실행 파일 `ShortTermPayroll-1.0.exe`도 같은 프로그램입니다. Windows용 .NET Framework 프로그램이며 설치 과정은 없습니다.

## 업데이트

- 기본값은 시작할 때 업데이트 확인입니다. 설정에서 끄거나 `지금 확인`으로 직접 확인할 수 있습니다.
- 새 버전이 있으면 안내 후 동의를 받아 실행 파일을 다운로드하고 SHA256을 검증합니다.
- 검증이 끝나면 다운로드 폴더를 엽니다. 현재 작업을 저장하고 프로그램을 종료한 다음 새 파일을 바탕화면에 옮겨 실행하세요.
- 인터넷 연결에 실패해도 현재 버전의 계산·저장·출력 기능은 계속 사용할 수 있습니다.
- 이번 정식 1.0은 이전 작업본 1.1에서 번호를 재정의한 배포입니다. 이전 1.1에서는 자동으로 낮은 번호를 설치하지 않으므로 정식 1.0 파일로 한 번 직접 교체해야 합니다.

## 유지한 수정 사항

- 당직 1인은 매일, 2인은 계약 시작일부터 격일 편성합니다. 무인경비요일(토요일 또는 일요일)의 해당 월 1~4번째 날은 비근무이며 5번째 날은 근무 순번을 따릅니다.
- 설·추석 당일과 전후 하루는 비근무로 편성하고, 나머지 공휴일은 근무 순번을 유지합니다.
- 전산실무사 자격수당 107,220원, 영양사 면허가산수당 117,220원을 적용합니다.
- 인건비 신청서의 야간시간을 시간·분으로 표시하고 급여명세서의 올바른 야간근로시간 칸에 입력합니다.
- 고용보험 제외 사유 입력, 주말 결근시간, 저장자료 및 서식 출력 개선을 포함합니다.

## 기존 자료

기존 설정 및 .stpay 파일을 계속 사용할 수 있습니다. 기존 달력에 새 당직 규칙을 적용하려면 대상자·계약의 `근무일 자동 편성`을 누르세요. 이 동작은 달력의 수동 조정·결근 표시를 초기화하므로 이후 실제 근무를 확인해야 합니다. 기존 저장자료의 수당 금액은 자동 변경하지 않습니다.
