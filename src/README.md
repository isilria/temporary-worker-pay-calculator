# 대체근로자 임금계산기 정식 1.4 소스

작성일 2026-10-15. 버전 1.4.0.0.

영역별 컬러 테마, 저장 질문 없는 종료, 계산 입력의 재실행 시 초기화, 임금산정표 XLSX 작업 복원을 구현했다. 1.2.0.2에서 검토한 Engine.cs는 변경하지 않았다.

## 빌드

Windows PowerShell에서 build.ps1을 실행한다. .NET Framework 4.x 컴파일러와 포함된 EPPlus 및 엑셀 양식을 사용한다. build/ShortTermPayroll.exe가 생성된다.

## 검증

- build-logic.ps1 → build/LogicAudit.exe 결과폴더절대경로: 계산·저장·금액·출력 40개 및 근무편성·수당·저장 145개.
- 같은 실행파일에 --excel-only 결과폴더절대경로: 기존 엑셀 생성·재열기 및 신청서 표기 164개.
- build-ui.ps1 → build/FlatUiTests.exe 결과폴더절대경로: 정사각형 날짜, 창 3개 크기, 6개 메뉴의 배치·겹침 등 60개.
- build-reopen.ps1 → build/ReopenTests.exe 결과폴더절대경로 기존산정표절대경로: 복원·입력 보존·편집·원본 보존·손상자료 거부 및 종료·재실행 검증. 기존 파일 인수로 test-fixtures/legacy-wage.xlsx의 절대 경로를 전달하면 된다.

검증은 가상 자료와 격리된 설정 파일을 사용한다. UI 검증 창은 작업 영역 밖에 만들고 활성화 및 작업 표시줄 표시를 하지 않는다. 일반 사용 창은 정상적으로 표시된다. build-preview.ps1은 개발자가 직접 볼 가상 예시 창을 생성하는 별도 도구다. 과거 --test는 이전 버전의 화면·PDF 검증도 포함하는 기존 시험용 진입점이며, 이번 버전 검증에는 위 전용 검증을 사용했다.

## 구현

- SessionAndTheme.cs: 기관 설정을 보존하는 종료·자료 열기와 영역별 색상.
- WageWorkbook.cs: 새 산정표 내부 복원자료 및 이전 일반직종 양식의 읽기. 원래 보고서의 OOXML을 그대로 유지하면서 VeryHidden 시트를 추가한다. 수식 캐시는 기존 ExcelReports.Patch 경로로 유지한다.
- 저장된 입력과 표시 표의 변경을 비교해 지원되는 입력 변경은 반영하고, 임의의 계산 결과 덮어쓰기·표 구조 변경은 거부한다. 파일 읽기·검증에 실패하면 현재 작업을 유지한다.
- 전체 주민등록번호는 산정표의 내부 복원자료에도 포함하지 않는다. 식별정보는 기존 보고서에 표시한 생년월일로 복원한다. .stpay는 기존 형식을 유지한다.
- 기관 설정에는 계산 입력을 추가하지 않았다. 기관 정보·테마·저장 폴더만 자동 저장하고, 계산 입력은 .stpay 또는 임금산정표에 사용자가 저장했을 때만 보관한다.

사용안내.md에 사용법과 기존 양식의 복원 한계를 설명했다. PDF 생성·외관은 이번 변경에서 재검증하지 않았다. 정식 배포와 자동 업데이트 절차는 루트 RELEASE.md에 정리했다.

## 1.4 신청서 표기 보완

직종명 → 원근로자 → 원근로자명 순서로 설명을 표시한다. 신청서 설명의 종료일은 같은 연도일 때 M. d.로 표시하고, 다른 연도일 때 yyyy. M. d.로 표시한다. 파일 버전은 1.4.0.0 그대로다. 정식 배포 소스에서는 계산 40개, 엑셀 164개, 근무편성·수당·저장 145개, 화면 60개, 복원 371개, 종료·기관 설정 25개, 업데이트 16개 등 821개를 다시 검사한다. 루트 package.ps1이 모든 전용 검사와 패키지 생성을 수행한다.
