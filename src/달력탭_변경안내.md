# 달력 탭 변경 · 정식1.4.0

파일 버전1.4.0.5. 정식1.4.0(파일1.4.0.3)을 바탕으로 달력 편집 대상을 세 탭으로 변경했다.

| 왼쪽부터 탭 순서 | 선택한 날짜 칸 | 의미 |
| --- | --- | --- |
| 계약근무일 | 연한 유칼립투스색 | 근로계약에서 정한 근무일 |
| 근무상황부 | 설정에서 고른 테마 색 | 실제 출근·결근·유급휴일 상태 |
| 통상근로자 근무일 | 회색 | 같은 기간 비교대상 통상근로자의 근무일 |

탭도 각 역할에 맞는 색을 사용한다. 근무상황부는 테마 선택 시 즉시 다시 그려지며 계약근무일의 유칼립투스색과 통상근로자 근무일의 회색은 유지한다. 근무상황부의 결근은 기존 노랑, 유급휴일은 초록, 미확인·비근무는 기존 표시를 유지한다. ‘출근 상태’ 드롭다운은 없어지고 ‘근무상황부’ 탭으로 바뀌었다. 탭은 왼쪽부터 시작하며 월 제목과 달력을 아래로 내렸다. 날짜 칸은 정사각형이다.

탭을 바꾸는 것만으로 계약·출근 자료나 지급액이 달라지지 않는다. 각 탭에서 날짜를 클릭해야 해당 입력을 편집한다. 새로 실행하면 계약근무일 탭으로 시작한다. 당직은 기존 별도 계산 방식과 근무상황부를 사용한다.

교육자료를 반영한 주휴 산식, 1.4 임금산정표 작업 복원, 메모·하단 확인 체크 제거, 종료 초기화, 기관 설정 보존, 신청서 표기 방식을 유지한다. 주휴일과 공휴일을 합산·상계하는 새 정산 기능은 이번 변경에 포함하지 않는다.

압축을 풀고 대체근로자_임금계산기_1.4.0.exe를 실행한다. 기존 정식 프로그램을 종료한 뒤 새 파일을 실행한다. 저장한 계산을 이어갈 때에는 자료 열기로 .stpay 또는 임금산정표를 불러온다. 기존 원본 파일은 보관한다.

실제 검사 기록은 검증결과.txt, 각 탭의 프로그램 자체 렌더링은 화면_*.png에 있다. 정식1.4.0 수정 배포에 포함된다.
