# 1개월 미만 대체근로자 임금계산기 · 정식 1.4

작성일: 2026-10-15. 파일 버전: 1.4.0.0.

## 실행과 변경 사항

[GitHub 최신 배포](https://github.com/isilria/temporary-worker-pay-calculator/releases/latest)에서 `ShortTermPayroll-1.4-windows.zip`을 받아 압축을 풀고 `대체근로자_임금계산기_1.4.exe`를 실행한다. 단일 파일 `ShortTermPayroll-1.4.exe`도 같은 프로그램이다. Drive에서는 `1.4_실행파일.zip`과 `대체근로자_임금계산기_1.4.exe`로 보관한다. Windows용 .NET Framework 프로그램이며, 엑셀 양식과 라이브러리가 실행파일에 포함되어 있다. PDF 저장에는 Microsoft Excel 설치가 필요하다.

- 근무 달력은 연파랑, 주휴 계산·시급 기준은 크림색, 추가 지급·자료 생성은 민트색, 공제는 연분홍색으로 영역을 구분했다. 단일 달력과 정사각형 날짜 칸을 유지한다.
- 앞서 재검토한 주휴 계산 엔진을 그대로 포함했다. 각 주의 산정시점 기준기간으로 계산하며 실제 근무·유급휴일·주휴를 구분한다.
- 종료할 때 계산자료 저장 여부를 묻지 않는다. 계산 입력은 자동 저장하지 않으며, 다음 실행은 빈 계산 화면에서 시작한다.
- 이름·생년월일·은행 계좌·원근로자·사유·직종 선택·근무일 선택·임금·공제·지급예정일·신청 차수는 이전 작업을 자동으로 불러오지 않는다. 직종은 기본 직종, 날짜는 실행일~6일 후의 기본값으로 돌아가고, 달력의 근무 선택과 계산 금액은 비워진다.
- 설정에서 직접 입력한 기관명·기관기호·담당자·연락처·테마·저장 폴더·업데이트 옵션은 유지한다. 상단 **초기화**도 기관 설정을 남기고 계산 입력을 비운다.

## 저장한 임금산정표로 이어서 작업하기

1. 계산을 마친 뒤 **명세서 · 신청서 → 임금산정표 → 엑셀 저장**을 누른다.
2. 나중에 프로그램을 실행해 상단 **자료 열기**를 누른다.
3. 저장했던 **임금산정표 `.xlsx`**를 선택한다.
4. 복원된 대상자·직종·계약기간·근무일·임금·공제를 수정한다. 주휴와 지급액은 현재 로직으로 다시 계산된다.
5. 수정한 결과를 엑셀로 다시 저장한다. 같은 이름이 있으면 번호를 붙여 새 파일로 저장하므로 원본 산정표를 유지할 수 있다.

미완성 계산을 보관하려면 상단 **저장**으로 대상자 자료 `.stpay`를 저장한다. 이 파일도 **자료 열기**로 계속 사용할 수 있다. 종료 시 자동 복구는 하지 않으므로 이어서 사용할 작업은 종료 전에 직접 저장한다.

## 새 파일과 기존 파일의 복원 범위

**1.4에서 저장한 임금산정표**에는 근무일별 상태, 소정근로시간, 직종, 임금·공제 입력, 기관기호·담당자·신청 차수·지급예정일 등의 복원자료가 포함된다. 일반직종과 당직직종 모두 지원한다. 복원자료는 인쇄되지 않는 내부 시트에 저장하며 원래 보고서의 수식·인쇄 영역을 유지한다.

임금산정표에는 기존과 동일하게 주민등록번호 전체를 저장하지 않는다. 엑셀에서 다시 열 때 식별정보는 **생년월일**로 복원된다. 주민등록번호 전체 등 작업 입력을 별도로 보관하려면 `.stpay`를 사용한다.

**기존 버전의 일반직종 임금산정표**는 표에 남아 있는 이름·직종·기간·근무 상태·계좌·시급·임금·공제를 읽어 복원한다. 표에 없는 기관기호·담당자는 현재 기관 설정을 기본값으로 사용한다. 신청 차수·지급예정일·고용보험 제외 사유 등은 확인해야 한다. 예전의 주휴 계산 결과를 고정값으로 가져오지 않고 현재 로직으로 재계산한다. 복원자료가 없는 예전 당직 산정표는 평일·주말·야간 입력을 정확히 복원할 수 없어 `.stpay` 또는 1.4 산정표가 필요하다.

새 산정표의 식대·세금·보험 공제, 성명·계좌 및 근무 상태처럼 읽을 수 있는 항목을 엑셀에서 수정했으면 그 변경을 반영해 재계산한다. 계산 결과를 임의로 덮어쓰거나 표의 구조를 바꾼 경우에는 복원을 중지하고 해당 항목을 안내한다. 당직 산정표의 수정은 프로그램에서 진행한다. 급여명세서·신청서·PDF는 이번 계산자료 복원 대상에 포함하지 않는다.

## 검산 예시와 검증

함께 제공한 **복원예시_주휴16.8시간.xlsx**를 자료 열기로 불러오면 실제 근무 12일·96시간, 유급휴일 3일·지급시간 18시간, 주휴 4.8+6+6=16.8시간, 실지급액 1,429,260원을 확인할 수 있다. 가상 자료이며 2026.9.15~10.8의 계속된 계약과 예시에 지정한 근무일·유급휴일 및 월~금 통상근로 편성을 전제로 한다.

주휴의 법령·해석 및 적용 전제는 **주휴수당_재검토_결과.md**, 실제 검사 결과는 **validation-1.4.txt**(실행 ZIP 안에서는 **검증결과.txt**)에 정리했다. 배포 소스로 계산·엑셀·신청서 문구·화면 배치·복원·종료·업데이트 821개 검사를 통과했다. PDF 생성·외관과 실제 프린터 인쇄는 이번 배포에서 재검증하지 않았다.

요약: 정식 1.4는 주휴 계산 개선, 영역별 색상, 질문 없는 종료와 계산 입력 초기화, 임금산정표 작업 복원, 신청서 문구·날짜 개선을 포함한다.


## 인건비 신청서 표기

직종명 → 원근로자 → 원근로자명 순서로 표시한다. 예: **초등돌봄전담사 원근로자 홍길동의 연차 대체(2026. 10. 15.~10. 20.)**. 같은 연도의 종료일은 연도를 생략하며 월이 달라져도 월·일만 표시한다. 연도가 다르면 **2026. 12. 28.~2027. 1. 3.**처럼 종료일에도 연도를 표시한다. 기존에 저장한 신청서에 반영하려면 프로그램에서 다시 저장한다.

## 업데이트

이전 정식 버전에서 시작 시 업데이트 확인 또는 설정 → **지금 확인**을 누르면 최신 버전을 안내한다. 다운로드에 동의하면 실행파일의 SHA256을 확인한 뒤 폴더를 연다. 현재 작업을 직접 저장하고 프로그램을 종료한 다음 새 파일을 실행한다. 게시 직후 버전 안내가 반영되는 데 수 분 걸릴 수 있다. 같은 번호의 1.4 테스트판을 사용 중이면 정식 1.4를 직접 받아 교체한다.

## 소스와 빌드

`src/build.ps1`로 빌드하고 `package.ps1`로 전용 검사와 배포 ZIP을 생성한다. 1.4는 기존 `--test` 대신 계산·엑셀·화면·복원·업데이트 전용 검사를 사용한다. 소스 ZIP과 저장소의 `src/README.md`, `RELEASE.md`에서 상세 절차를 확인한다.
