# 1.5.0 공휴일 갱신 기능

- 2025~2027년 공식 공휴일 날짜·명칭 자료를 실행파일에 포함했습니다. 임금 단가와 보수 기준은 기존 2026년 자료를 유지하므로, 다른 연도의 금액 기준은 별도로 확인해야 합니다.
- 프로그램을 시작하면 공휴일 자료를 먼저 확인하고 기존 프로그램 업데이트도 확인합니다. 시작 시 자동 확인은 설정의 ‘시작 시 프로그램·공휴일 확인’으로 조절합니다.
- 날짜 추가·삭제·이름 변경이 있으면 ‘연간 공휴일 일정이 변경되었습니다’와 해당 날짜·명칭을 표시합니다. 같은 내용은 다시 알리지 않습니다.
- 검증된 자료는 PC에 저장합니다. 인터넷에 연결되지 않으면 마지막 정상 저장 자료를 사용하고, 저장 자료가 없거나 손상되면 실행파일의 내장 자료를 사용합니다.
- 설정의 ‘공휴일 확인’으로 수동 갱신하고 ‘일정·변경 내역’에서 연간 일정·최근 변경·원천 자료 확인 시각을 볼 수 있습니다. 공휴일이 없는 날짜와 해당 연도의 자료 자체가 없는 경우를 구분합니다.
- 저장자료(.stpay)와 임금산정표(.xlsx)에 적용한 공휴일 자료 버전과 계약기간의 공휴일 목록을 함께 기록합니다. 다시 열 때 변경이 있으면 안내하고 재계산합니다. 원본 저장파일을 자동 덮어쓰지 않습니다.
- 공휴일 변경 시 계약일·출근·결근 입력은 유지합니다. 변경된 휴일에 맞춰 통상 비교일을 갱신하고 계산 결과를 다시 보여줍니다. 실제 출근일이 공휴일로 바뀌거나 기존 유급휴일이 취소된 경우에는 기존 계산기의 확인 안내에 따라 근무상태를 수정해야 합니다.

## 수집과 반영 시점

공식 API → 관리하는 GitHub 파일 → 각 PC 순서입니다. 공식 자료 수집은 매시간 시도하도록 준비했으며, GitHub 예약 실행이 지연되거나 공식 API에 변경이 아직 반영되지 않았으면 프로그램에서도 즉시 반영되지 않습니다. 프로그램에는 원천 확인 시각과 PC에서 확인한 시각을 구분해 표시합니다.

인증키는 실행파일·공개 데이터·소스에 포함하지 않습니다. GitHub 저장소 비밀 설정 등록과 기본 브랜치 반영 승인이 완료되면 자동 수집을 활성화합니다. 이 테스트 빌드에서는 두 작업이 승인 대기 상태이며, 현재는 검증된 내장 자료로 사용할 수 있습니다.
