# 교육공무직원 320일 근무 편성기 1.12.3

`src/build.ps1`로 Windows EXE를 빌드합니다. .NET Framework 4.x가 필요합니다.
`src/verify.ps1`은 계산·화면·엑셀 생성·비동의자·공휴일·프로그램 업데이트 검사를 실행합니다.
`package.ps1 -OutputDirectory <새 폴더>`로 검증 후 EXE, 소스 ZIP, 검증 기록과 SHA-256을 만듭니다.

상단의 **업데이트 확인**은 320일 편성기 전용 공개 배포 정보를 조회합니다. 새 버전은 동의 후 다운로드하고 SHA-256·프로그램명·버전을 확인합니다. 현재 실행파일과 입력값을 덮어쓰지 않습니다. 다운로드 후 현재 창을 닫고 새 EXE를 사용합니다.

업데이트 정보는 `workday/latest.json`, 배포 태그는 `workday-v버전`으로 다른 계산기와 구분합니다.

엑셀 비고는 같은 이름과 유급·무급 구분을 가진 연속 휴일을 `24일~26일 추석`처럼 묶습니다. 날짜가 떨어져 있거나 대체공휴일·지급 구분이 다르면 별도로 표시합니다. 월을 넘는 연휴는 각 월에 표시합니다.
