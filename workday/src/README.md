# 교육공무직원 320일 근무 편성기 1.12.3

파일 버전 1.12.3.0

## 변경 사항
- 화면을 시안 B 레이아웃으로 개편했습니다. 학년도·방학 기간·재량휴업일·기타 휴일 카드와 12개월 달력이 입력 즉시 반영됩니다.
- 달력 날짜를 오른쪽 클릭하면 재량휴업일, 임시공휴일, 약정근무일을 지정/해제할 수 있습니다.
  - 재량휴업일: 방학 중 지정 불가(오류 안내), 학년도 4일 한도.
  - 임시공휴일: 방학 중에도 지정 가능.
  - 약정근무일: 방학 중 평일만. 소정근로일수에 포함되며 그 주 토·일이 유급으로 인정됩니다.
- 방학 중 공휴일만 있는 주의 토·일은 편성·유급하지 않습니다.
- 출력물은 매크로 없는 .xlsx(3개 시트)입니다. 달력 수정은 프로그램에서 합니다.
- 연차휴가 지정 기능은 삭제했습니다.
- 국가데이터포털 공휴일 조회와 연도별 로컬 저장은 그대로입니다.

## 빌드·검증
Windows에서 build.ps1 로 빌드하고 verify.ps1 로 검증합니다. 기존 Excel COM 매크로 검사는 `obsolete_excel_macro_tests`로 옮겼습니다.
